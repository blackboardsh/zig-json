Initial smoke benchmark, 2026-10-04
Linux ARM64 shared host, Zig 0.16.0, ReleaseFast.
One run; not a statistically controlled cross-library comparison.
778,903 bytes, 10,000 records; warm input; complete contiguous output.
Benchmark uses std.heap.page_allocator for Zig-owned allocations.

Mode                    microseconds/op
std_full                  7307.787
native_full               4561.830
retained_write            2641.684
scan_splice               4729.525
indexed_splice             225.301

Both full modes parse a typed schema, edit one boolean, and encode all output.
retained_write uses already-parsed native Zig state; indexed_splice uses an
already-indexed source. Their setup is excluded. scan_splice includes input
validation, source copy, indexing and output generation on every operation.
Native typed output currently constructs a yyjson mutable DOM before encoding;
direct schema-specialized writing could avoid that intermediate representation.

Reproduce: zig build bench -Doptimize=ReleaseFast
Do not compare these numbers directly with the earlier json-benchmark probes:
this dataset, allocator, safety/ownership policies and workload are different.
